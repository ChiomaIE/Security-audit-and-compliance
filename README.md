# Cybersecurity portfolio - audit and risk assessment activities.

This repository contains the *security audit* and *risk assessment* activities I completed as part of the Google Cybersecurity Professional Certificate.

My first project involved conducting a controls and compliance audit of Botium Toys, a fictional retailer. I audited the company's security posture against three
frameworks: PCI DSS, GDPR, and SOC Type 1 and Type 2 criteria. During the assessment, I reviewed fourteen security controls across the administrative, technical,
and physical categories, evaluated the company's compliance gaps and then developed recommendations to address the identified risks.

The completed audit checklist is included in this repository. The key finding
was a risk score of 8 out of 10, The assessment identified weaknesses in encryption, access control, and backup and recovery capability.

The project helped me develop practical skills in security auditing, risk assessment, compliance evaluation and security control analysis.
